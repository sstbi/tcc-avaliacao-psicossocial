# Requisitos do Sistema

## Objetivo
Desenvolver um sistema web para apoio à gestão da avaliação psicossocial ocupacional.

## Requisitos Funcionais
- RF01: Cadastrar empresas clientes
- RF02: Listar empresas cadastradas
- RF03: Editar dados de empresas
- RF04: Inativar empresas
- RF05: Cadastrar unidades vinculadas às empresas
- RF06: Listar unidades cadastradas
- RF07: Editar dados de unidades
- RF08: Inativar unidades

## Requisitos Não Funcionais
- O sistema deverá ser web
- O sistema deverá utilizar banco de dados PostgreSQL
- O sistema deverá permitir versionamento via GitHub
- O sistema deverá possuir documentação no repositório
